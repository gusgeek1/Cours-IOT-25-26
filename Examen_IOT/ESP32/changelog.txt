# Changelog – Projet Nichoir (ESP32 TimerCAM)

## v0.4 – Capture photo manuelle (Test caméra)
- Ajout d'un bouton "Tester la caméra" dans la page de configuration
- Implémentation d'une nouvelle route `/capture` pour capturer une photo
- Implémentation d'une route `/photo.jpg` envoyant la photo JPEG brute au navigateur
- Gestion d'un buffer global `lastPhoto` pour conserver temporairement la photo
- Correction de la fonction d’envoi : remplacement de `send_P()` (incompatible) par un envoi binaire via WiFiClient
- Capture désormais fonctionnelle en AP comme en STA
- Aucun changement visuel majeur pour préserver le design de la v0.2
- Streaming vidéo totalement retiré (plus utilisé)
- Base solide pour la future capture automatique via PIR

## v0.3 – Mode WiFi Client (STA) + Fallback AP + /info
- Lecture complète du fichier config.json (WiFi + paramètres MQTT FUTURS)
- ⚠️ Le Raspberry Pi n’est PAS encore utilisé dans cette version
- Connexion automatique au WiFi en mode STA
- Timeout de connexion WiFi (10 secondes)
- Retour automatique en mode AP si la connexion échoue
- Ajout d’un endpoint /info affichant l’état réseau en JSON
- Conservation de la page de configuration complète (v0.2)
- Scan WiFi toujours actif dans la page de configuration
- Suppression complète du streaming vidéo /video
- Code caméra initialisé uniquement pour usage futur

## v0.2 – Interface de configuration avancée
- Ajout du scan automatique des réseaux Wi-Fi
- Menu déroulant pour choisir un SSID détecté
- Interface stylée avec logo et mise en page moderne
- Sauvegarde de la configuration (WiFi + MQTT) dans /config.json via SPIFFS
- Redémarrage automatique après sauvegarde
- Remplacement de l’ancienne v0.2 par cette version

## v0.1 – Streaming vidéo (base du projet)
- Mode AP initial : TimerCam-AP / 12345678
- Page web simple de test
- Flux vidéo MJPEG en temps réel
- Orientation caméra corrigée (vflip + hmirror)
- Première version pour valider le matériel TimerCAM
